Filters
----------

Photometric filters are implemented as instances of the ``Filter`` class.
These can be loaded easily as 

.. code:: python
    
    from fiesta.filters import Filter
    filt = Filter(name)

Here, ``name`` can be any filter that is built-in as a bandpass in `sncosmo <https://sncosmo.readthedocs.io/en/stable/bandpass-list.html>`_ .
